# 九人德州 · 桌面版

单机无限注德州扑克（9 人桌）：14 个性格各异的机器人从角色池随机入座，风格会随战绩动态漂移（诈唬反馈、上头、对你的读牌攒够样本后生效），金额全程以 BB 计。

## 运行方式

**最简单**：双击 `index.html`，用 Chrome / Edge 打开就能玩，不需要安装任何东西。进度和设置都保存在浏览器本地，重开自动恢复，不会像手机预览那样清零。

**Electron 桌面窗口（可选）**：装好 Node.js 后在本目录执行：

```
npm install
npm start
```

会打开一个独立的软件窗口（骨架已配好；没装 Electron 时用上面的双击方式即可）。

## 功能

- **内置回放**：牌桌下方点「⏪ 牌局回放」，本桌最近 60 手可逐手、逐步回放（上一步/下一步/自动播放），结算步亮出所有未弃牌者底牌；也能载入手机版导出的 `holdem-review.json` 回放手机上打的牌局。
- **快捷下注（可自定义）**：翻前预设 = 加注到多少 BB（默认 2.5 / 3 / 4 / 5），翻后预设 = 底池百分比（默认 33% / 50% / 66% / 100%），跟其他扑克软件一样的摆法；在「快捷下注设置」里改成你顺手的数值，点按钮即出手，无需确认。滑杆和数字框可微调（0.5BB 步进）。
- **键盘快捷键**：F 弃牌 · C / 空格 让牌或跟注 · A 全下 · 1–4 对应当前快捷下注按钮 · ↑ / ↓ 调加注额 · 回车 确认加注 · N 开始下一手。
- **数据互通**：导出/导入的 JSON 与手机版完全同格式；战绩、筹码、复盘记录可跨设备转移，也可发给 Muse 做带注释的复盘。
- 机器人不自动补码（输光离场、角色池补位）；你输光自动重买 50BB，每手结束约 2.6 秒自动开下一手。

## 目录

- `index.html` — 成品（游戏 + 回放 + 设置，单文件）
- `main.js` / `package.json` — Electron 骨架
- `src/game.js` — 游戏逻辑源码
- `src/replay-module.js` — 回放模块源码（构建时拼入 index.html 的脚本后半段）
- `tests/` — 无头测试（牌力评估与独立实现 600 次交叉对账、边池、300 手筹码守恒模拟、桌面功能检查）

## 测试

```
cd tests
cat test_prelude.js ../src/game.js tests.js > /tmp/t.js && node /tmp/t.js
```

（成品 index.html 的脚本与 src 拼接结果一致，验收以成品文件为准。）

## 装到 iPhone 主屏幕（免开发者模式）

把仓库推到 GitHub 并开启 Pages（或把 `index.html` + 两个图标文件放到任意静态托管）后：

1. iPhone 用 **Safari** 打开页面链接
2. 点底部分享按钮 → **添加到主屏幕**
3. 桌面出现「九人德州」图标，点开是全屏应用界面，进度保存在 Safari 的站点数据里、不会重开清零

说明：这走的是网页应用路线，不需要开发者模式、不需要签名。真正的开发者模式侧载（Xcode/AltStore 安装原生包）需要你自己的电脑和 Apple ID 在本地签名，免费证书 7 天过期，不推荐为了这个游戏折腾。
